# React + TypeScript Application

Клиентское веб-приложение, построенное на **React** и **TypeScript** с использованием **rsbuild**.  
Проект ориентирован на масштабируемость, строгую типизацию и удобство разработки.

---

## Технологии проекта

В проекте используется следующий стек технологий:

- **React v18** — построение пользовательского интерфейса
- **TypeScript** — строгая статическая типизация
- **rsbuild** — сборка проекта и dev-сервер
- **Tailwind CSS** — utility-first стилизация
- **i18next** — интернационализация и локализация
- **MSW (Mock Service Worker)** — мокирование API-запросов
- **PostCSS** — обработка CSS
- **ESLint / Prettier** — контроль качества кода (опционально)

Архитектура проекта основана на подходе **Feature-Sliced Design (FSD)**.

## Установка и запуск проекта

### Требования

- Node.js >= 18
- npm / yarn / pnpm

### Установка зависимостей

```bash
npm install
# или
yarn install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу:

http://localhost:3000


### Сборка проекта

```bash
npm run build
```

### Предпросмотр production-сборки

```bash
npm run preview
```

## Мокирование API

MSW используется только в режиме разработки и не включается в production-сборку.
Для тестирования каких либо записей или кода на номер телефона, необходимо в дев режиме менять данные в файле /src/mock/handlers.ts
Так для примера, если мы хотим изменить код подтверждения телефона при регистрации необходимо изменить следующие строки
```const VALID_SMS_CODE = '123456';```
